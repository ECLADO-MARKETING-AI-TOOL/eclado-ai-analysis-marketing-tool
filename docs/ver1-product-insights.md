# Ver.1 · 통합 매출 메뉴와 상품·리뷰 분석

## 확정 범위

2026-10-20 대화 요청자가 중복 매출 분석 메뉴 제거와 네 개의 하위 화면 구성을 승인했습니다. 사이드바는 제목 `매출 분석` 아래 `매출 요약`, `매출 추이`, `고객별 매출 추이`, `매출·상품·리뷰 AI` 한 목록으로 구성합니다. 독립되어 있던 이전 상품·리뷰 예제 메뉴를 현재 매출 데이터 기반 분석으로 대체하며 공식 카탈로그·기존 가격·용량/EAN 표는 네 번째 화면에 보존합니다.

데이터 선택은 네 화면 모두 같은 `SalesRepository`와 매출 API를 사용합니다. 별도 가상 리뷰 시나리오를 현재 더미 실적으로 혼합하지 않습니다. 생성형 AI·실제 메시지 발송은 추가하지 않습니다.

## 계산 기준과 상태

| 항목 | 기준 | 상태·근거 |
|---|---|---|
| 긍정/부정 상품 Top 10 | 선택 기간 작성된 구매 연결 리뷰에서 긍정(4~5점)/부정(1~2점) 건수 내림차순. 해당 리뷰가 1건 이상인 상품만 최대 10개. 동률은 상품 ID순 | 기존 점수 분류를 사용한 초안. NLP 감성 추론 아님. 최종 순위 정책 승인 담당자/일자 확인 필요 |
| 리뷰 급증 Top 10 | 조회 종료일 기준 최근 7일과 직전 7일 비교. 양의 증가 건수순, 동률은 최근 건수·상품 ID순. 최대 10개 | 제안: 7일 비교/증가 건수순. 사용자 시각 검토 대기. 14일 이력 미제공이면 목록 없음. 기준 0건은 증가율 null과 설명 표시 |
| 월 이동평균 매출 급변 | 종료일 기준 최근 30일 일평균 vs 직전 30일 일평균. 상대 변화 절대값 10% 이상, 경계 10% 포함. 비교의 60일 전체 이력 필요 | 사용자 요청: 월 이동평균/10% 이상. 비중첩 30일 비교는 명시한 초안 해석이며 최종 회계 정책 승인 아님 |
| 신제품 제외 | 종료일에서 출시 후 30일 이내(30일 포함) 상품 제외 | **확정**: 2026-10-20 대화 질문에 요청자가 해당 기준 선택 |
| 출시일 미제공 | 확정 급변 목록에 포함하지 않고 `출시일 확인 필요 · 매출 급변 후보`로 구분 | 확인 필요: 현재 더미는 출시일 미제공. 첫 구매일/카탈로그 관측일을 출시일로 추정하지 않음 |
| 매출·주문수량 변화 폭 | 직전/최근 매출, 일평균, 매출 증감액·증감률, 결제 상품 수량과 수량 증감·증감률 | 매출은 기존 순상품매출/환불 완료일 차감. 주문수량은 결제 상품 수량(환불 차감 전)으로 명시 |
| 연령층 급변 | 같은 30일/10% 기준. 각 비교 구간 모두 기여 고객 5명 이상인 연령층만 표시 | 제안: 상품과 동일한 임계값. 구매 시점 제공 연령 기준, 환불도 원구매 연령 연결 |

직전 매출이 0 또는 음수인 상품/연령층은 상대 증감률을 산출하지 않아 급변 목록에서 제외합니다. 직전 주문수량이 0이면 수량 증감률은 null입니다. 비교는 조회 종료일 기준이며, 선택 기간 시작일과 관계없이 명시한 이전 60일/14일 이력을 사용합니다. 고객 성별·연령·구매 동기 등을 리뷰 문구에서 추정하지 않습니다.

## 출시일 데이터 계약

더미 계약의 선택 필드 `product_launch_dates`는 `{상품 ID: ISO 날짜}` 형식입니다. 실제 운영 API 필드 매핑이 아닙니다. 기존 파일은 빈 매핑으로 호환됩니다. 카탈로그에 없는 ID, 데이터 종료일 이후 출시일, 출시 이전 구매가 있는 입력은 거부합니다. 데이터를 받지 못한 현재 저장 파일은 수정하지 않습니다.

## 검증과 복구

- 10% 상승/하락 경계, 10% 미만 제외, 30일 신제품 제외, 미확인 출시일 분리, 비교 60일 이력 부족, 리뷰 증가 0기준/Top 10 제한, 연령층 소표본 숨김 테스트.
- 통합 네 메뉴/로그인·로그아웃/새로고침 복원, 공식 카탈로그 116개 가격·용량/EAN 보존, 매출/고객 화면 회귀 테스트.
- 실제 로컬 API 기준 2026-10-20 종료 조회: 리뷰 급증 10개, 출시일 확인 필요 급변 후보 98개, 연령층 급변 4개. 기존 10월 순상품매출 96,788,655원 유지.
- pytest 36개, Ruff/mypy 통과. 실제 로컬 API를 호출하는 AppTest로 네 번째 화면 표·정렬·임계값·카탈로그 확인. 실제 브라우저 픽셀 검토 미실시.
- 롤백: UI/insights 서비스/선택 DTO 필드를 이전 버전으로 복원 후 서버 재시작. DB 적용이나 더미 재생성 불필요. 운영 데이터/API 승인·출시 완료를 의미하지 않음.
