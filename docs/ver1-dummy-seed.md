# Ver.1 · 2,000건 더미 연동 시험

2026-10-20 대화 요청에 따라 실제 실행 중인 로컬 API에 저장한 합성 데이터입니다. 실제 ECLADO 거래·고객·리뷰가 아닙니다.

## 데이터와 저장 위치

- 고객 2,000명: 남녀 각 1,000명, 2026년 기준 10~80대, 시·군·구까지 25개 지역. 이름·전화번호·상세 주소는 수집하지 않습니다.
- 주문 2,000건: 구매 고객 1,600명, 그중 400명은 2회 주문, 나머지 고객 400명은 미구매. 한 주문에 서로 다른 상품 1~5종, 항목별 수량 1/2/3/5개.
- 상품 항목 5,292개, 수량 7,609개. 기존 공식몰 카탈로그 116개 상품, 확인된 용량/EAN을 포함한 128개 상품·용량 조합. 미확인 규격은 null이며 임의 EAN을 만들지 않습니다. SKU 마스터를 새로 확정한 것은 아닙니다.
- 리뷰 작성 고객 400명(전체 고객의 20%): 1인 1건, 총 400건. 긍정 4~5점 200건, 부정 1~2점 200건. 문구는 `[가상 리뷰]`로 표시하며 구매 고객·주문·항목을 참조합니다. 중립 평점은 이번 표본에 없습니다.
- 상품 항목 환불 200건: 일부/전체 항목 환불, 지연·월 경계 환불, 조건에 따른 배송비 환불. 전체 주문 환불과 항목 전체 환불은 구분합니다.
- 기간 2020-01-01~2026-10-20: 최근 활동을 늘린 가상 분포이며 이전의 무거래일도 합성 시나리오에서 0원입니다. 실제 이력 보유를 뜻하지 않습니다. 구매 시 연나이가 10세 미만인 주문은 만들지 않습니다.
- 저장: 기존 `LocalDummySalesStore`의 `.local/sales_dummy.json`에 영구 보관. JSON 기반 로컬 테스트 저장소이며 Supabase DB에 적재한 것이 아닙니다. 서버 재시작 뒤에도 유지되고 Git에서 제외됩니다.

가격은 가상 주문 생성 시 현재 보관된 카탈로그 판매가를 시작값으로 복사하고 할인액을 별도로 생성했습니다. 과거 실제 가격·매출을 복원한 것이 아닙니다. 이후 집계는 항목에 저장된 가격/할인만 사용하며 원본 카탈로그 가격·규격 파일은 수정하지 않습니다.

## 연결 경로와 검증

`tools/seed_dummy_sales.py` → admin repository → typed API → import service → local store. 읽기는 매출 API → 분석 service → 응답 DTO → repository → Streamlit입니다. SQL·Supabase·실제 고객 접근은 추가하지 않았습니다.

지역과 리뷰, 항목 용량/EAN은 기존 버전 1 더미 계약의 선택 필드로 추가했습니다. 이전 JSON은 지역/규격 null, 리뷰 빈 목록으로 호환됩니다. 리뷰의 중복 ID/구매 항목, 작성 고객 불일치, 구매 이전/범위 밖 작성일을 거부하며 잘못된 입력은 기존 데이터를 교체하지 않습니다.

- 직접 계산한 순매출과 API의 일별·월별·상품별·성별·연령별·지역별 합계가 일치합니다. 동일 데이터 재전송 결과는 `unchanged`로 중복 합산되지 않습니다.
- 저장 데이터 해시: `d10657975a57a133c931289dfda19ed38f9a70fc8cb41e110c3e897f7ee13449`.
- 31개 자동 테스트 통과. 지역/리뷰 연결·필터·작성일·잘못된 입력 시 보존·금액 대사 포함. Ruff/mypy 통과.
- 실제 로컬 API를 사용하는 AppTest로 로그인, 세 매출 페이지, 지역/리뷰 표, 여성·80대 필터, 로그아웃을 확인합니다. 브라우저 픽셀 검토와 운영 Supabase 연동 검증은 범위 밖입니다.

## 화면과 재현

로그인 후 `매출 분석` → 분석 데이터 `업로드 더미 데이터` 선택. 전체 데이터를 보려면 2020-01-01~2026-10-20을 선택합니다. 기본 월 범위에서는 해당 월의 주문·작성일 기준 리뷰만 표시합니다.

매출 요약과 고객별 매출 화면의 구매 연결 리뷰 표에서 리뷰 수/평균 평점 열을 클릭해 정렬합니다. 4~5점/1~2점 분류는 명시적인 점수 기준이며 AI 감성 분석이 아닙니다. 지역별 금액은 기존처럼 기여 고객 5명 미만이면 숨깁니다. 기존 `상품·리뷰·AI` 메뉴의 가상 시나리오는 별도 데이터이며 이번 더미 시험 결과는 매출 분석 메뉴에서 확인합니다.

API/Streamlit을 켠 상태에서 다음 명령으로 같은 시나리오를 재생성할 수 있습니다. **기존 업로드 더미 전체를 교체**하므로 다른 시나리오를 보존하려면 먼저 `.local/sales_dummy.json`을 백업하세요.

```powershell
uv run python tools/seed_dummy_sales.py
```

복구: 테스트 저장 파일을 백업본으로 복원하면 이전 시나리오로 돌아갑니다. 제거 시에는 `실제 실적 · 연동 대기`를 선택하고 해당 로컬 파일만 삭제합니다. 이번 작업에서는 요청대로 저장된 데이터를 제거하지 않습니다. 운영 정책/API 접근·보관 승인은 계속 확인 필요이며 실제 발송·DB 마이그레이션·커밋은 없습니다.
