# Ver.1 용량·EAN 연결 기록

2026-10-20 요청: 상품 분류 열·필터를 제거하고 영문 엑셀을 한국어 상품과 대조해 용량·EAN만 추가한다. 모든 기존 가격은 유지한다.

## 원천과 연결 방법

- 원천 파일: `260511_ECLADO_Price_List_KRW (1).xlsx`, `ECLADO_Products_List` 시트의 C열 Items·D열 Capacity·K열 EAN13. Sample 시트는 규격·EAN이 없어 사용하지 않았다. 엑셀 원본은 수정·복사하지 않았다.
- 상품 라인·기능·제형·영문 고유명과 한국어 표기를 대조하고, 다중 용량은 공식몰 공개 상세의 용량 옵션까지 확인했다. 이름의 유사도만으로 자동 연결하지 않았다.
- 결과: 공개 카탈로그 116개 중 82개 상품·94개 규격 연결, 34개 상품 연결 보류. 영문명·원천 행 번호·용량·문자열 EAN·원본 파일 SHA256을 별도 참조 데이터에 보존한다. EAN은 수치 계산·반올림하지 않는다.
- 규격 참조는 `backend/eclado_backend/stores/data/product_specifications.json`에 분리했다. 카탈로그 ID와 검토한 한국어 이름이 모두 일치할 때 적용하며, 재수집 후 이름이 바뀌면 임의 재매칭하지 않고 확인 필요로 표시한다.
- 공개 가격 스냅샷·관측·상품명·상품 수는 그대로다. `public_catalog.json`의 변경 전후 SHA256은 `0b06433a4fe2b5239890ce0197752126e1eb1aa2a9f37e8fe2e910d4a8d16c52`로 동일하다. 엑셀 가격은 참조 데이터와 API에 가져오지 않았다.
- 분류는 화면·카탈로그 응답·실적 표에서 제거했다. 기존 공개 수집 스냅샷의 분류 근거는 과거 관측·수집 범위 검증용으로 보존하며 표시하거나 필터링하지 않는다.

엑셀에서 서로 다른 영문 상품에 동일 EAN이 있는 경우 원본 값을 보존하고 별도 확인 사항을 표시한다. 대상은 안티셉틱 스프레이/엑소 클리니카 토너, 내추럴 퍼펙트 선크림/엑소 클리니카 겔, 화이트닝 인핸서 비비/엑소 클리니카 크림이다. 원본 값을 새로운 번호로 고치거나 이 EAN만으로 상품을 병합하지 않는다.

연결 보류 및 부분 연결·중복·미기재 사유는 화면의 **용량·EAN 확인이 필요한 상품**에서 확인할 수 있다. 한 상품에 여러 용량이 있으면 EAN 열에 `용량: EAN` 쌍을 표시하며, 대표 EAN 하나로 합치지 않는다.

## 검증과 복구

- 테스트: 용량별 EAN 쌍, 선행 0 문자열 보존, 단위 충돌·세트 자동 연결 금지, 원본 중복 표시, 전체 가격·관측 시각 불변, 분류 필터 제거·용량/EAN 렌더링 확인.
- `uv --cache-dir .cache/uv run --offline --no-sync pytest -p no:cacheprovider`: 16 passed. 같은 uv 옵션의 `ruff check .` 통과, `mypy` 31개 소스 파일 통과. 기존 테스트 종료 임시파일 정리 권한 경고·Ruff 탐색 경고는 남아 있으며 종료 코드는 모두 0.
- Streamlit 재시작 후 실제 로컬 API에 연결한 AppTest에서 상품 116개·분류 필터 없음·용량/EAN 렌더링·셀메모리 규격별 EAN·두 모드 예외 없음·가격 파일 해시 불변을 확인했다. 로컬 서버 health 정상.
- DB·마이그레이션·실제 고객 데이터·발송·커밋 변경 없음. 복구는 규격 참조와 응답·표시 변경을 되돌리고 로컬 서버를 재시작한다. 가격 스냅샷을 복원하거나 엑셀 원본을 수정할 필요는 없다.
